# 拼豆图纸

在浏览器里把像素图转成拼豆图纸。图片不会上传到服务器：取样、色号匹配、预览和导出都在本机完成。

## 环境

- Node.js 20 或更高版本
- npm

## 启动

```bash
npm install
npm run dev
```

终端会打印本地地址，用浏览器打开即可。开发服务默认是 `http://localhost:5173/`。

## 其他命令

```bash
npm run build    # 类型检查并生成 dist
npm run preview  # 预览构建结果
npm run check    # 色差、取样、选区和分页的自检
npm run lint     # 代码检查
```

## 使用

1. 上传 PNG、JPG 或 WebP。
2. 先选品牌，再选该品牌的色号范围。默认是 MARD 221 色。
3. 按需要调整豆阵宽度。小图默认按原图像素宽度取豆。
4. 在预览里沿轨迹选择格子并改色，或打开吸色，从原图取色后涂到选中的格子。
5. 下载 PNG，或按 A4 横向分页下载 PDF。

屏幕上的颜色只供对照，实物以豆子为准。
